# Kieran 的学术主页

- 个人主页：https://kieran0625.github.io/

简洁的学术型个人网站，展示个人简介、研究兴趣、研究项目、开源工具与学习资源。使用原生 HTML 和 CSS，无需构建或安装依赖；支持桌面、手机和打印。

## 维护

- `index.html`：个人信息、项目说明和链接。
- `assets/home.css`：页面样式与响应式布局。
- `assets/profile.png`：来自个人公开 GitHub 资料的头像，可替换为个人照片。
- `assets/favicon.svg`：站点图标。

直接编辑文件后提交到 `main`，GitHub Pages 从仓库根目录自动发布。本地预览可运行 `python3 -m http.server 8000`，然后打开 `http://localhost:8000/`。

页面只展示已有公开资料中的项目与链接。补充学校、院系、教育经历、论文、学术服务、简历或 Google Scholar / ORCID 时，使用已确认的真实资料；Fork 课程保留相应标注。

工程伦理习题库入口指向 https://kieran0625.github.io/buaa-engineering-ethics/，其源码和部署由 [buaa-engineering-ethics](https://github.com/kieran0625/buaa-engineering-ethics) 独立维护。
